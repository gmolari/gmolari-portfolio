# gmolari-portfolio

Portfólio gamificado de **Guilherme Molari**, Senior Software Engineer (full stack, gamificação e iGaming).

Um site que se joga: mundo explorável, conquistas, XP e minigames, com um modo "pular cutscene" limpo e indexável para recrutadores.

## Stack (planejada)

- Next.js (App Router) + TypeScript + Tailwind CSS
- Motion para animações de UI · PixiJS v8 para o mundo e os minigames
- SEO completo: Metadata API, OG images dinâmicas, JSON-LD, sitemap, robots, hreflang
- Deploy na Vercel
